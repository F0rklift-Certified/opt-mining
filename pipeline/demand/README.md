# Electricity Demand Pipeline

Consolidated pipeline for downloading, validating, inspecting and aggregating AEMO NEM operational demand data.

## Quick Start

```bash
# Full pipeline (download → validate → inspect → aggregate → feature)
python -m pipeline.demand

# Skip download, use existing CSV
python -m pipeline.demand --skip-download --input-csv path/to/existing.csv

# Run only the aggregation stage
python -m pipeline.demand --only aggregate --input-csv path/to/existing.csv

# Custom date range
python -m pipeline.demand --start-date 2023-07-01 --end-date 2026-06-30
```

## Stages

| # | Stage | Description | Output |
|---|-------|-------------|--------|
| 1 | **download** | Fetch half-hourly ZIPs from AEMO NEMWeb, consolidate into single CSV | `aemo_operational_demand_YYYYMMDD_YYYYMMDD.csv` |
| 2 | **validate** | Strict quality gate (6 checks). Halts pipeline on failure. | Pass/fail (no file) |
| 3 | **inspect** | Statistical summary: regional stats, temporal completeness, data quality | `inspection_summary.txt` |
| 4 | **aggregate** | Annual mean demand per NEM region | `demand_annual_summary.csv` + `.meta.json` |
| 5 | **feature** | Uniformly allocate regional demand to the common grid (proxy) | `aemo_demand-proxy_2026_nsw.gpkg` + method report |

## CLI Options

```
--start-date      Start date YYYY-MM-DD (default: 2025-07-01)
--end-date        End date YYYY-MM-DD (default: 2026-06-30)
--only <stage>    Run only one stage: download, validate, inspect, aggregate, feature
--skip-download   Skip download (use existing CSV)
--skip-validate   Skip validation
--skip-inspect    Skip inspection
--skip-aggregate  Skip aggregation
--input-csv       Path to existing consolidated CSV (use with --skip-download)
--output-dir      Output directory (default: DATA/electricity-demand/)
--verbose         Detailed logging
```

## Output: `demand_annual_summary.csv`

One row per NEM region. This is the primary output for downstream use (Task 5 spatial allocation).

| Column | Unit | Description |
|--------|------|-------------|
| REGIONID | — | NEM region (NSW1, QLD1, SA1, TAS1, VIC1) |
| MEAN_DEMAND_MW | MW | Annual mean operational demand |
| MAX_DEMAND_MW | MW | Annual peak demand |
| MIN_DEMAND_MW | MW | Annual minimum demand |
| STD_DEMAND_MW | MW | Standard deviation |
| SUMMER_MEAN_MW | MW | Mean demand Dec–Feb |
| WINTER_MEAN_MW | MW | Mean demand Jun–Aug |
| START_DATE | — | Pipeline start date |
| END_DATE | — | Pipeline end date |

## Architecture

```
pipeline/demand/
├── __init__.py      # Package docstring
├── __main__.py      # CLI orchestrator (argparse, stage routing, error handling)
├── config.py        # Shared constants (paths, URLs, defaults)
├── download.py      # Stage 1: AEMO NEMWeb download + consolidation
├── validate.py      # Stage 2: 6-check quality gate
├── inspect.py       # Stage 3: Statistical summary report
├── aggregate.py     # Stage 4: Annual regional summary
└── README.md        # This file
```

Each module exposes a `run()` function that can be imported independently:

```python
from pipeline.demand.validate import run as validate
from pipeline.demand.aggregate import run as aggregate

result = validate(csv_path=Path("data.csv"))
agg_csv, meta = aggregate(csv_path=Path("data.csv"), output_dir=Path("."), ...)
```

## Data Source

- **Publisher:** Australian Energy Market Operator (AEMO)
- **Dataset:** Actual Operational Demand — Daily (half-hourly intervals)
- **URL:** https://nemweb.com.au/Reports/Archive/Operational_Demand/ACTUAL_DAILY/
- **Licence:** Public data, free to use with attribution to AEMO
- **Coverage:** NEM regions only (NSW, QLD, SA, TAS, VIC). WA and NT not covered.

## Validation Checks

1. No duplicate (REGIONID, INTERVAL_DATETIME) pairs
2. Timestamp continuity (30-min intervals, no gaps)
3. No mixed temporal resolutions
4. All 5 NEM regions present
5. OPERATIONAL_DEMAND is numeric
6. No null/NaN demand values
